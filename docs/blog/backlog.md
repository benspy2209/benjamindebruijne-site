# Backlog du blog

Le premier sujet de « À écrire » est le prochain article. Un sujet = une ligne : angle, 2-3 points à couvrir, sources à ouvrir.

## À écrire
1. **CSV vs CSA : ce qui change vraiment pour un chef de projet** — angle : la pensée critique remplace la documentation par réflexe ; couvrir : d'où vient le CSA (FDA, guidance Computer Software Assurance 2022, finalisée en 2025 ? vérifier), ce que GAMP 5 2e éd. en a repris, 5 décisions concrètes qui changent dans un plan de validation, ce qui ne change pas (Part 11, annexe 11) ; sources : FDA, ISPE.
2. **GP0→GP4 expliqué à quelqu'un qui démarre en pharma** — angle : un cycle stage-gate générique (ne pas présenter comme propre à une société), ce qu'on attend à chaque gate, les livrables typiques (charter, URS, DCS, plans de validation, rapports), les erreurs des nouveaux ; sources : GAMP 5 (cycle de vie), PMI pour le stage-gate en général.
3. **Un LLM via API en environnement GxP : figer, qualifier, journaliser** — angle : on ne maîtrise pas le modèle, donc on traite le fournisseur comme un fournisseur ; couvrir : version épinglée, qualification fournisseur (GAMP 5 annexe M2), jeu de cas, journalisation, revue périodique, changement de modèle côté fournisseur, données envoyées ; sources : ISPE, EMA reflection paper 2024, AI Act.
4. **DT SME : à quoi sert ce rôle et pourquoi il manque sur beaucoup de sites** — angle : le traducteur entre Labs/Production/Qualité et IT ; couvrir : 4 responsabilités, à quoi on le reconnaît, quand le créer, ce qu'il n'est pas (ni PM, ni architecte) ; pas de source réglementaire nécessaire, rester descriptif, ne nommer aucun site.
5. **IT/OT : les cinq questions qu'un responsable Qualité doit poser à l'IT** — angle : la convergence IT/OT crée des risques que la Qualité ne voit pas ; couvrir : inventaire, segmentation, accès privilégiés, intégrité des données des automates, plan de continuité ; sources : ISA/IEC 62443 (vue d'ensemble), GAMP 5, annexe 11.
6. **La matrice de traçabilité qui tient en inspection** — angle : l'outil le plus sous-estimé du dossier de validation ; couvrir : URS → FS/DCS → tests, ce qu'un inspecteur y cherche, les 4 erreurs classiques (exigences non testables, tests orphelins, versions divergentes, mise à jour oubliée au change control), un gabarit minimal ; sources : GAMP 5, annexe 11 §4, Part 11.
7. **Intégrité des données en 2026 : ALCOA+ au-delà du slogan** — angle : appliquer chaque lettre à un système réel ; sources : PIC/S PI 041, MHRA GxP Data Integrity guidance 2018, annexe 11.
8. **Revue périodique d'un système validé : la faire sans y passer une semaine** — angle : checklist proportionnée au risque ; sources : GAMP 5, annexe 11 §11.
