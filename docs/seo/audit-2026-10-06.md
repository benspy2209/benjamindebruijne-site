# Audit SEO / GEO — benjamindebruijne.com — 2026-10-06

Périmètre : 66 URL (FR + EN), build local = prod. Lighthouse mobile home : perf 95, a11y 96, best-practices 100, SEO 100. LCP 1,5 s, CLS 0.

## Ce qui est bon
- robots.txt ouvert à tous les crawlers (GPTBot, ClaudeBot, PerplexityBot inclus), sitemap déclaré, 69 pages indexables, 404 réel.
- canonical + hreflang fr/en/x-default dans le head de chaque page, lang fr-BE / en-GB.
- 1 seul h1 par page, titres et descriptions présents partout, FAQPage JSON-LD sur services / à-propos / piloter.
- HTTPS + HSTS, assets `_astro` immutables, vidéo hero 456 Ko, fonts auto-hébergées préchargées.
- Redirections 301 des anciennes URL Lovable en place.

## Problèmes (par priorité)

### Haute
1. **Person JSON-LD trop pauvre** : pas de `sameAs` (LinkedIn, GitHub), pas d'`image`, pas de `knowsAbout`, pas de `WebSite`/`ProfessionalService`. C'est LE signal d'entité pour Google et les LLM.
2. **Pas de llms.txt / llms-full.txt** (GEO).
3. **Meta description par défaut dupliquée** (179 car., trop longue) sur /, /contact, /projets, /blog, /confidentialite, /mentions-legales (+ équivalents EN à 166 car.).
4. **Titres projets non qualifiés** : « Beneloo — Benjamin de Bruijne » (29 car.) alors que `tagline` existe. Idem « Produits & projets. », « Parlons de votre projet. » (ponctuation dans le title).
5. **Titres offres trop longs** : 76-80 car. FR, 66-77 EN (coupés dans la SERP).

### Moyenne
6. **Pas de BreadcrumbList** sur projets / offres, pas de `Service` JSON-LD sur les 3 pages d'offre.
7. **/blog disallow dans robots sans noindex** : la page peut être indexée « sans contenu ». Mieux : noindex + retirer le Disallow.
8. **Headers sécurité absents** (X-Content-Type-Options, Referrer-Policy, Permissions-Policy, X-Frame-Options) → vercel.json.
9. **OG incomplet** : pas d'og:locale, og:site_name, og:image:width/height/alt, twitter:title/description. og.jpg unique pour 66 pages.
10. **a11y link-name** : le CTA header `.hdr__cta` n'a pas de nom accessible sur mobile.

### Basse
11. 36 logos clients en `alt=""` : décoratif OK, mais nommer les clients (alt « UCB ») renforce les signaux d'entité.
12. Images : benjamin.jpg (196 Ko JPEG) et logos PNG → WebP/AVIF, ~180 Ko économisables.
13. Sitemap : alternates hreflang seulement sur 12 des 66 URL (slugs FR/EN différents), pas de lastmod. Couvert par le head, non bloquant.
